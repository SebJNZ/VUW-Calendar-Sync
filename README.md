# VUW-Calendar-Sync
Want to be up-to-date and transparent with changes on due dates, lecture times, while still retaining full backup of calendars, look no further than VUW Calendar Sync.

# Support
Currently VUW Calendar Sync only supports the ECS calendar.

In the future we look to support [timetable.victoria.ac.nz](https://timetable.victoria.ac.nz/)'s calendar for lecture, tutorial and lab times.
